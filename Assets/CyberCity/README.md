# Neural Lockdown / 赛博街区

打开 `Assets/Scenes/CyberCity.unity`，点击 Play。新场景已设为 Build Settings 第一个场景；旧庭院场景保留。

## 操作

- WASD / 方向键：移动；武器自动选择有射击视线的最近敌人。
- Tab：跟随镜头 / 全城视图切换。全城视图不暂停战斗。
- ESC：暂停；R：重开。
- E：背包面板（打开时暂停战斗）。左侧 2/5 为武器、鞋子、攻速配件栏，右侧 3/5 为 24 格背包，支持穿脱、替换和删除确认。开局为空，装备由怪物掉落，靠近自动吸附；五档品质使用对应图标与光柱。R 重开清空本局装备。详情见 `Docs/背包装备与掉落系统.md`。

- F：打开/关闭测试对话；鼠标或数字键 1～4 选择分支，无分支时 Space / Enter 继续，ESC 关闭。对话期间暂停战斗，与背包互斥。详见 [对话系统](../../Docs/对话系统.md)。

## 当前美术接入

- 玩家使用 `cyber_operative_player_sheet.png`。
- 近战电击棍士兵、远程安保机器人使用最新的 `cyber_security_enemies_sheet_v3.png`。近战轮廓已扩展以保留棍身和电光。
- 智能弹、蓝色脉冲弹使用 `cyber_projectiles_effects_atlas.png`。
- 地面使用 `cyber_ground_64x44_32px.png` 单张 Sprite：2048×1408、PPU 32、Pivot Center、Point 过滤、无压缩和 mipmap。场景内 Ground 位于原点、缩放为 1，独立 Ground Sorting Layer 排在 Default 下方。
- 建筑和装饰继续使用 `cyber_city_tileset_atlas.png` 的独立道具网格，与地面分离；未使用室外/研究设施两张整图。
- 角色沿用静态帧、方向翻转和轻微运动起伏。母图背景通过轮廓网格裁掉大部分，局部仍有底色残留，并非完整逐帧动画。

## 地图

64×44 单位，面积约为原 28×16 地图的 6.3 倍。

- 1 张地面背景，355 个独立环境物件。旧的 786 块拼片已归入 `Legacy tiled ground - disabled`，整组停用。
- 电力交换区：变压设备、电力柜、管线、空调外机。
- 安保节点：检查岗亭、摄像头、警示路障、围栏和门。
- 服务街区：售货机、花箱、垃圾桶、垃圾袋、集装垃圾箱。
- 冷却维护区：涡轮、通风设备、维护钢板和排水设施。
- 十字主干道、斑马线、外环和巷道连接各街区。

115 处矩形碰撞区域由 `CyberCityWorld.obstacles` 管理，包含设备岛、主要路障、侧边围栏及外边界。锥桶、标识、部分小型装饰不参与碰撞。选择游戏管理对象可查看橙色碰撞线框。

## 玩法适配

- 镜头跟随玩家，并限制在街区边缘附近；Tab 可查看全图。
- 全地图随机刷怪，距离玩家至少 8 单位，同时避开障碍和不可达网格。
- 玩家移动按小步分解并沿障碍滑动，避免大步长穿墙。
- 敌人共用从玩家位置反向计算的网格距离场，通过巷道绕障。
- 自动索敌和机器人射击检查视线，投射物撞到主要实体障碍后消失。
- 刷怪初始间隔 0.8 秒，随时间缩短至最低 0.42 秒，最多 85 个敌人。
- 近战生命固定 58，远程固定 82；已删除生命时间成长与随机差异。

## 代码和调整

- `Assets/PlagueSurvivor/Scripts/CyberCityWorld.cs`：碰撞、距离场、视线、镜头。
- `PlagueGame.cs`：原有战斗逻辑，按是否绑定 city 启用城市规则。
- `PlagueSpriteOutlines.cs`：新旧两套角色的轮廓网格。
- `Editor/CyberCityBuilder.cs` 和 `Editor/CyberCityPolish.cs`：通过 Unity MCP 执行的场景构建与细化工具。
- `Editor/CyberCityArtUpdate.cs`：在城市场景中执行 Apply，将旧拼片升级为单张地面，配置 Ground Sorting Layer，并更新 v3 敌人预制体；可重复执行。
- 场景内可直接移动和替换物件；若改变实体障碍位置，请同时更新对应的 obstacles 数组。

- `DialogueScript.cs` / `DialoguePanel.cs`：分支脚本、运行时对话 UI；`Assets/CyberCity/Resources/TestDialogue.asset` 是当前测试脚本。
