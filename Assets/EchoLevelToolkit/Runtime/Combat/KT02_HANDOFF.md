# KT-02 shared combat handoff (2026-09-23)

Base `7dde3aec8cf7060b825be4464e7ad18ebfdcb91a`; Foundation API v0 from KT-01 original `0343e59`. This branch changes only `Runtime/Combat`, `Preview`, and `Content/Combat`. It does not change any Native component, shared Foundation signature, asmdef, package, or project setting.

## What is in the branch

- `CombatWorld` binds exactly one `LevelInstanceContext` to one player and explicitly registers enemies and bosses. It has no global actor registry. `EnemyDied` comes from `CombatEnemy.ReceiveDamage` when positive, finite damage takes live health to zero; `OnDisable`/`OnDestroy` only unregister. Projectiles belong under the world so unloading the instance removes them.
- `CombatPlayer`, `CombatWeapon`, `CombatProjectile`, `CombatEnemy`, `CombatFanAttack`, and `CombatBoss` reproduce the saved Native values and mechanics. The Boss keeps alternating tracked burst/bombardment, shell armor, recurring core windows, three second support extension, and E as the only terminal action. `TryActivate` returns `Started`, `AlreadyActive`, `NotRunning`, `MissingReference`, `InvalidConfiguration`, or `Defeated`. Encounter code must commit Active and close doors only after `Started` (or deliberately handle `AlreadyActive` for an idempotent call).
- `CombatSight` uses one parent-aware `CombatObstacle` marker for line of sight, projectile sweep, enemy short feeler, warning clipping, bomb reach, and core E. It is not pathfinding. Obstacle colliders in imported Tilemaps must carry the marker on the collider object or a parent.
- `Preview/CombatPreview.unity` holds only `CombatPreviewHost`, four `CombatTemplate` references and generated solid-color shapes. Play: WASD, Space, E near the exposed core, R restart. It spawns the standard player, Pulse, Security Drone, Arc Sentry, then starts the Boss after **two real enemy deaths**. No quest, narrative, HUD, Native run host, or old BossArena runtime type is referenced. A failed Boss activation leaves its `bossActivated` flag false; no door is created or closed. There is no completion claim beyond the Boss E result.
- The four `.asset` templates are copies of actual saved Prefab values, not the source code defaults alone. Their `sourceFingerprint` is SHA-256 of the source files listed below, concatenated in order. The preview uses runtime-created shapes solely as self-made placeholders; no old generated art is packaged.
