# Chunk Map authoring

Open **Echo → Level Toolkit → Map Authoring**. Enter `author/work/local`, size 3–32, and up to one continuous half-open port on each side. The tool creates an independent `ChunkDefinition → Grid → Ground / Obstacles / Decoration / Overhead` prefab under `Works/<author>/<work>/Chunks`. Paint `TileBase` assets on those Tilemaps with Unity's Tile Palette; ordinary Tile assets and shared RuleTile assets both work. `Obstacles` has `TilemapCollider2D`. Put object decorations under `Details` and give each `ChunkDecoration` marker a unique local ID.

Create a `ChunkMap` root and place saved prefabs at integer origins through the same window. The map component owns the configurable `Cell World Size` (default 1, still a physical-play candidate). Its children remain prefab instances. The Scene view shows square footprints and port intervals. The window reports overlap and facing-port gaps; it does not generate roads, seal gaps, rotate, mirror, or bake instances. Map geometry checks do not establish player clearance or obstacle behavior in combat queries.

**Echo → Level Toolkit → Create Map Sample** generates a shared rectangular Tile Palette, simple 32×32 pixel / 32 PPU placeholder Tiles, four Chunk prefabs of sizes 3, 5, 6, and 32, and an isolated `ChunkMapSample.unity` scene. The sample includes a WASD circle-collider walk probe. It does not modify `NativeDemo`. Existing sample prefabs and scene are preserved on repeat generation. Use an isolated Unity Editor slot to run this menu; the source checkout alone does not contain the generated assets.

For later AI changes, open the target Chunk in Prefab Mode and use **Echo → Level Toolkit → AI Chunk Merge**. The sample generator records a baseline on newly created Chunk prefabs. For an externally generated Chunk, explicitly record its first AI-authored baseline in the merge window. Existing resources without a baseline cannot be merged. Select a proposal prefab with the same stable content ID and size. The preview compares the last AI baseline, current content, and proposal across Tilemap cells, ports, theme, and marked decoration object trees. Only unchanged-current cells and properties are selected automatically. Human changes remain unselected, including when a proposal happens to match them; select a specific row to adopt it. Apply uses Unity Undo for the prefab-stage edits and baseline asset. Save the prefab after reviewing the result.
