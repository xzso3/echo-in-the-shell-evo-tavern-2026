# GF01 全流程 UI 布局草案与装配规范

设计基准：1280×720，CanvasScaler `Scale With Screen Size`、Match 0.5。像素边缘用 Point/Clamp 的 Sprite；所有中文、数值、输入、按钮命中区、错误和真实状态用 uGUI/TMP。优先保留世界画面，主菜单、轻面板、HUD、平板与结果各有不同厚度的表面语言。美术图只提供环境、装饰和图标。下文矩形均为参考分辨率的屏幕坐标 `(x,y,w,h)`，左上为原点；实施时用锚点和安全边距适配，不锁死屏幕像素。

## 视觉基准和层级

- 背景石墨 `#111B1F`，轻面板 `#18282B`，线条 `#426650`，主字 `#D5E8D8`，次字 `#88A498`，行动薄荷 `#9CDEB3`；琥珀 `#DFB16D` 仅用于待授权合同，损失/失败 `#CF8A78`。设置中的“已配置”只表示必要字段存在，绝不作为连接成功灯。
- TMP 优先使用工程现有中文 FusionPixel 字体与 fallback。标题约 32–42，节标题 20–24，正文 18–22，辅助 15–18；长文案不写入贴图。按钮的可点高度至少 44，面板关闭和确认按钮至少 48。
- 绘制序：世界 / 氛围遮罩 / HUD / 平板 / 暂停菜单 / 共享 AI 设置 / 返回确认 / 结局呈现 / 结算 / 场景加载错误。一次只允许当前最上层接收输入；所有纯装饰图 `raycastTarget=false`。
- 任何界面不显示一句固定的世界冻结状态播报。暂停菜单以“暂停”作为界面标题即可。

## 1. 主菜单和共享 AI 设置

**主菜单**：全屏设施远景。右半的道路/机房保留负空间，左侧 `(72,70,520,580)` 是薄终端区域，只有切角、竖线和透光边角，不套平板厚壳。`(96,90)` 处原生 TMP 游戏标题两行；其下 1 行副标题。三个垂直按钮从 `(96,330)` 开始，宽 360、高 56、间隔 14：开始游戏 / AI设置 / 退出游戏。底部 `(96,592,420,44)` 为配置状态及测试状态，文案来自配置/测试结果；“已配置”“离线模式”不会被误写为“已连接”。

**设置**：从主菜单或暂停菜单打开同一个表单 View，保留调用方。全屏半透明遮罩，中央偏右 `(322,72,636,576)` 薄边面板，顶行标题与返回。纵向字段为 API Base URL、模型 ID、API Key、超时；Key 为遮盖输入并有独立清除动作，空白不覆盖已有内存 Key。底部右对齐测试连接、应用，左对齐取消；测试反馈独立两行，溢出允许换行。局内设置使用相同组件，关闭后回暂停菜单并保持世界暂停。原生 ScrollRect/布局组保障窄屏及输入法顶起时可达。

## 2. 开局说明、暂停、返回确认

这组共用轻量九宫面板边框与 44–56 高按钮，不使用完整平板外壳。

**开局说明**：场景加载完成即显示全屏暗幕 0.72，中央 `(280,116,720,488)` 面板。顶行“操作说明”，中间 2×2 键位格：WASD 移动、Space 开火／停火、E 互动、Tab 平板；下方一行“开始行动后本局计时与战斗启动”。主按钮“开始行动”置右下 `(748,526,212,56)`。Esc 不跳过，游戏输入全部被遮断。若加载失败，显示具体可读错误与返回主菜单，不能留死界面。

**暂停**：世界暗幕 0.55，右侧 `(778,108,402,504)` 窄面板，标题“暂停”，下面三个纵向按钮：继续游戏 / AI设置 / 返回主菜单。背后世界仍可辨认。Esc 在此等价继续；局内设置关回此面板。

**确认返回**：高于暂停的遮罩和居中 `(378,235,524,250)` 小对话框；正文“本局进度不会保存”；左右按钮“取消”“确认返回”。Esc 与取消同义，回暂停面板。确认后禁用重复操作，若加载出错重新给可操作入口。

## 3. 游玩 HUD 与世界互动

**上缘**：左上 `(24,22,286,88)` 放生命数字/条，右上 `(924,22,332,62)` 放当前目标，一段最多两行。仅用窄角件和细框；中间上缘留空给战斗。同步度/差异度若原有 HUD 在场，显示为简短数字与小线条，不增加第二块大型仪表。

**下缘**：左下 `(24,630,310,66)` 显示开火状态/装备提示；右下 `(940,630,316,66)` 为 Tab 平板提示。交互在世界目标附近或底部居中 `(390,604,500,70)` 临时出现：E 键帽、动作与目标名；消失时不留占位黑框。危险/受击只以短暂状态色变化表达，不占中心瞄准区。所有目标、血量、按键状态由代码驱动。

## 4. 战术平板与合同

平板严格沿用 `PhoneUI/Art/TacticalTabletFrame.png` 和现有六张配套 Sprite；整体居中 1088×612，内容安全区、三页签、输入和物理返回键坐标按 `Docs/AICommander/UI02_ASSETS.md`。保留聊天 ScrollRect、支援、记录三个入口。连接状态、生命、草稿、回复、提案、手动支援由 TMP/uGUI 绘制。**不重新生成平板外壳或已有图标。**

合同在平板显示开口**内部**覆盖聊天，不覆盖外壳，约 `(273,179,734,360)`。从上到下：标题/关闭、真实效果、涉及记忆、授权范围、同步度变化、失效原因、接受并执行/拒绝。关闭、Esc 或物理返回键先取消合同并回原聊天位置；下一次输入才关平板。合同等待、失效、已执行状态均用原生色块/细线/文案切换，不需要新合同贴图。琥珀只在待授权阶段使用。

## 5. 结局、新生接续和结算

**普通结局呈现**：渐暗世界但不套设施主菜单背景；中央 `(244,156,792,408)` 为稀疏双边线文本区域。上方小编号/状态线，原生 TMP 结局名称 34、原有短文本 20–22，底部“查看本局结果”按钮。玩家主动点击才进结算，不倒计时切换。四类名称和内容由 Narrative 提供，不烘焙于美术。

**新生**：第一拳、终拳、黑屏及平板接续按原机制；演出期隐藏 HUD 和暂停入口。平板接续返回键和明确可见的“查看本局结果”都转入结算，不回战斗。此支不另加角色插画/动画资产。

**结算**：暗世界底，中央 `(180,72,920,576)` 轻量数据终端面板。顶部 `(230,112,820,94)` 为成功结局名称或失败标题“意识涣散”、一句真实总结。中段四个整洁数据格 `(230,242)` 起，按本局用时、击败敌人、同步度、差异度排序；禁止评分、星级或排名。其下最多三条关键经历，每条由真实事件决定，无记录时整区收起或显示单句“尚无关键记录”。底部两个 56 高按钮：“再来一局”或“重试” / “返回主菜单”。失败以小面积损失色标记，背景与布局不另画一套。

## 原生组件与交接

| 组件 | 原生实现 | 图像装饰 | 状态/数据来源 |
| --- | --- | --- | --- |
| 主菜单入口 | `Button` + TMP | 轻边、按钮底 | 导航、配置存在性 |
| 设置表单 | TMP_InputField、Toggle/Slider、Button | 共用薄面板 | CommanderSettings、独立测试反馈 |
| 说明/暂停/确认 | Button + TMP、CanvasGroup | 轻面板、键帽 | Flow/Pause 顶层状态 |
| HUD/互动 | TMP、Image 填充、条件显隐 | 小边角/键帽 | NativeHud、互动目标、装备 |
| 平板/合同 | 既有 uGUI、ScrollRect、TMP | 既有七 Sprite | Phone/Commander/Support 真值 |
| 结局/结算 | TMP + Button + LayoutGroup | 细边框/结果面板 | Narrative、RunResultSnapshot |

GF01-05 可先按上述矩形和层级建立原生组件，不等待图像。GF01-06 同理先接真实数据和既有平板；最终 Sprite 应作为可替换 `Image` 装饰层。INT 负责唯一共享场景、NativeHud/Phone 和字体引用合并，确保没有旧结果面板叠加。若具体接口仍在 GF01-00 协调，以此文布局和状态优先接现有组件，不猜造业务真值。
