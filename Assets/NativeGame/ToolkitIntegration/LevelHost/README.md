# NB-01 Native level host

This directory contains the Native adapter for a selected, installed level work. It does not change `NativeDemo`. Importing a prefab or opening its preview does not call `Mount`.

## Authoring and runtime contract

Put `NativeLevelPlacement` on the root of the work prefab and assign its `LevelStage`, `ChunkMap`, `MapDoorSet`, `CombatWorld`, `CombatPlayer`, optional `CombatWeapon`, and `LevelEndpointCatalog`. All assigned scene components and the Stage player spawn must be descendants of the root. `Stage.LevelId` and `Catalog.LevelIdentity` must match; `Stage.Doors` must be the assigned door set. For camera limits, either supply explicit world bounds or let the placement derive them from all valid Chunk placements plus padding. The selected work prefab must be passed explicitly by the installer/selection flow.

`NativeLevelHost` takes explicit `NativeRunController` and `NativeCamera` references. Its `BeginRun` is invoked from `NativeRunController.Started`, creating one new `RunId` for that Native run. It does not mount a level. Call `Mount(prefab, worldOrigin, integratedBinding, out instance, out diagnostic)` after the work has been selected. Each call clones the work and creates a new `RuntimeScope` with a unique `LevelInstanceId`, including when the same prefab is placed twice. Only `LevelRunMode.Integrated` is accepted. The host initializes that instance's `CombatWorld`, `CombatPlayer`, optional weapon, `LevelBindingSession`, `LevelStage`, and scoped `LevelEventEmitter`s before it exposes the instance. A missing required binding fails the mount; it never falls back to Sandbox.

`TryGet(scope, out instance)` and `Focus(scope)` require the exact RunId and LevelInstanceId. `instance.Session` carries the same scope and rejects foreign events/actions. `Focus` selects one instance for the Native camera and restores the prior target/bounds after the last focused instance is removed. The first mount is focused automatically. A later mount is not focused until the caller chooses it. `Unmount(scope)` and `UnmountAll()` stop the instance contexts, deactivate placement roots immediately, unbind emitters, dispose Stage and session, then destroy all owned children. Combat projectiles are children of `CombatWorld`; fan warnings and Boss hazards are children of their actors. Death and Native run termination unload every mounted instance. A local `ExitReached` event remains in the selected Integrated binding; it never calls `NativeRunController.Complete` here.

Only the focused instance simulates combat. An instance can run during its own synchronous mount initialization so `CombatWorld.Initialize`, `Session.TryStart` and `Stage.StartBound` succeed; before it is exposed, a nonfocused instance is paused. Paused instances stay mounted with their actor health, encounter state, door state and binding session intact. `TryGet` and `Focus` still accept a paused instance, so focus can resume it without rebuilding its run or level identity. Combat movement stops through `ILevelRunContext.IsRunning`; temporary projectiles and warnings may clear while paused under the toolkit combat behavior. Only a death reported by the currently focused instance can end the Native run. Unmounting a focused instance chooses another mounted instance if one exists; unmounting a paused instance leaves focus alone.

| Operation | Focused instance | Other mounted instances | Native run |
| --- | --- | --- | --- |
| Mount first / later copy | First gains focus; later copy stays paused | Health, encounter and door state retained | Continues |
| Focus another scope | New focus resumes | Previous focus pauses | Continues |
| Unmount focused / paused | Another mounted scope gains focus / current focus stays | Removed scope and its session are disposed | Continues |
| Focused actor dies | All scopes unload | All scopes unload | Native death callback runs once |
| Native run ends or restarts | All scopes unload | All scopes unload | Original Native lifecycle owns result/restart |

## INT-LT scene wiring

1. Add `NativeLevelHost` only to the new integration scene and assign that scene's Native run and camera. Leave the saved `NativeDemo` entry and its three memory/Boss/ending wiring intact.
2. Supply a selected imported `NativeLevelPlacement` prefab and an NB-03 `Integrated` binding. The binding subscribes to the chosen catalog's real events; it must inspect the event's `RuntimeScope` and map only explicitly chosen endpoint IDs to Quest/Narrative facts. Do not install a Sandbox binding in this session. `LevelEventEmitter.Raise` must be called only by the verified physical interaction source; the host binds/unbinds its per-instance session.
3. Connect NB-02 input, interaction and support target selection to the focused `CombatPlayer`/Boss and use `Mounted`/`Unmounted` to clear references. The current toolkit `CombatWorld.Initialize` permanently binds one `CombatPlayer` to one instance. Two simultaneously active instances therefore need distinct CombatPlayers and Worlds; the old `NativePlayer` cannot simply be reused as both worlds' actor. The integration scene must explicitly direct player input to the focused actor and keep Native run phase/death in sync. The host calls `NativeRunController.PlayerDied()` when a toolkit player dies. Do not attach both movement controllers to one Rigidbody2D.
4. Add a scene builder or installer selection call to `Mount` only after the work is selected. Use distinct `worldOrigin` values for copies. Keep `NativeMap` fixed gates for the old scene; author doors live in the placement's `MapDoorSet`.
5. After KT-05 is integrated, compile S1 and run one S4 mount/exit/unmount in the new scene. Verify old NativeDemo starts, then defer the full two-instance matrix as agreed. Check missing scripts, an Integrated required binding failure, door reset, removed projectiles/warnings, camera restoration, and that test exits do not end the Native run.
