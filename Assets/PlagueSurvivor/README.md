# 瘟疫庭院：基础生存原型

打开 `Assets/Scenes/PlagueCourtyard.unity`，点击 Unity Play。该场景已加入 Build Settings 首位。

- WASD / 方向键：全向移动，斜向速度归一化。
- 弩箭自动锁定 9 单位内最近的敌人，无需鼠标操作。
- ESC：暂停 / 继续；R：随时重开。
- 左上显示生命和击杀，右上显示存活时间。生命归零后按 R 重试。

## 基础参数

| 项目 | 参数 |
| --- | --- |
| 庭院 | 28 × 16 单位，四边限制移动，无内部碰撞障碍 |
| 玩家 | 100 HP，速度 4.5，受伤无敌 0.65 秒 |
| 弩箭 | 22 伤害，0.48 秒间隔，速度 13 |
| 近战丧尸 | 44 HP，速度 1.75，接近至 0.72 单位后攻击，12 伤害，1 秒间隔 |
| 吐酸丧尸 | 66 HP，速度 1.25，在 4～6 单位间保持距离，9 单位内射击，16 伤害，2.4 秒间隔 |
| 酸液 | 速度 4，发射时瞄准玩家当前位置，可通过移动躲避 |
| 刷怪 | 全图随机，距玩家至少 6 单位；64 次采样均失败则跳过；出生 0.7 秒保护 |
| 节奏 | 初始 5 只；新怪 28% 为吐酸怪；间隔从 1.15 秒逐渐降至 0.42 秒；上限 65 只 |

选中 `Game - Tune parameters here` 可修改玩家、地图范围、刷怪、攻击参数。地图美术尺寸固定，修改地图范围时也需调整场景地面和围墙。

## 结构与素材

- `Scripts/PlagueGame.cs`：移动、索敌、攻击、刷怪、简单分离避让、线段投射物命中、UI 和重开。
- `Scripts/PlagueSpriteOutlines.cs`：运行时为角色创建轮廓网格，同步朝向、受伤颜色和前后遮挡顺序。
- `Editor/PlagueSceneBuilder.cs`：通过 Unity MCP 调用的编辑器场景构建器。已有场景不应重复运行 Build。
- `Prefabs/`：近战怪、吐酸怪、弩箭、酸液弹。
- `Sprites/`：从原始母图裁切的 Sprite 资产。角色采用轮廓网格减少背景，不修改原始 PNG 像素。
- 母图仍有底色残留，轮廓和动作属于原型质量；当前使用静态朝向图、左右翻转与轻微移动起伏，未制作完整逐帧动画。
- 地图使用母图中的石板、鹅卵石、泥地与墙体；边界通过代码限制，墙体为视觉标记。
- Unity 2021.3 / URP 12，Point 过滤、无贴图压缩与 mipmap。像素相机使用该版本的 Experimental 命名空间。
- UI 使用 TMP 与随包字体；当前游戏内标签为英文。

## 验证记录

通过 Unity MCP 在 Play Mode 运行检查：

- 直向和斜向移动 1 秒均为 4.5 单位；越界移动被限制在地图内。
- 中心与四角共 2,500 次刷怪位置采样全部满足 6 单位安全距离，实测最小值 6.002021。
- 最长 60 秒战斗模拟（死亡即停止）触发了 15 次击杀、34 次玩家射击、6 次吐酸和 7 次玩家受伤。
- 死亡界面、重开后的生命 / 时间 / 击杀 / 初始怪物数量复位均通过。
- 投射物使用扫过线段检测，快速弩箭不会因为跨帧越过敌人而漏判。
- 编译检查无 C# 错误。未打包独立可执行程序。
