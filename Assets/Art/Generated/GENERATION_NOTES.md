# 中世纪丧尸危机美术母图

生成方式：Codex 内置 `imagegen`。

## 文件

- `medieval_survivor_crossbow_sheet.png`：玩家四方向动作、弩箭四方向、命中特效。
- `medieval_zombies_sheet.png`：近战丧尸、吐酸丧尸、酸液弹与酸液落地效果。
- `plague_town_environment_atlas.png`：地面、过渡块、墓地/集市/教堂废墟等场景道具。

## Unity 原型导入建议

- Texture Type：Sprite (2D and UI)
- Filter Mode：Point (no filter)
- Compression：None
- Generate Mip Maps：关闭
- Pixels Per Unit：先以 32 为基准，再按实际游戏画面校准
- Sprite Mode：Multiple（角色和敌人需要手工按内容框切片）

## 当前限制

这些图片是 AI 生成的视觉母图，并非严格像素坐标网格成品。角色和敌人图虽然提示要求透明背景，但输出仍保留了深色氛围底；正式投入游戏前需抠底、统一每帧画布、校正脚底锚点，并进行像素级清理。地图图集适合作为风格基准与原型切图来源，正式 Tilemap 应重排为严格的 32×32 图块。

## 最终生成规格

### 玩家与弩箭

中世纪尸潮生存游戏用 Unity 2D 像素角色动作表；兜帽棉甲、皮护腕、暗红围巾、手弩；下/左/右/上四方向，每方向包含待机、两帧行走和射击姿势；另含四方向弩箭与命中特效。32×32 角色观感、正交俯视三分之四视角、有限色板、硬像素边缘、统一比例和锚点，无文字与 UI。

### 丧尸

两种中世纪丧尸的 Unity 2D 像素动作表：瘦削近战瘟疫丧尸、喉部发出病态绿光的臃肿吐酸丧尸；四方向、两帧行走、攻击、受伤与倒地姿势；另含酸液弹和三帧酸液落地效果。32×32 生物观感、正交俯视三分之四视角、低饱和尸绿和褐色布料、清晰轮廓、不过度血腥，无现代元素。

### 地图图集

中世纪瘟疫城镇的 Unity 2D 俯视像素环境图集；磨损鹅卵石、泥地、枯草、教堂石地和酸液地面，以及地面过渡块；包含破车、桶箱、火堆、墓碑、枯树、铁栅栏、石墙、摊位、骨堆、火把、废井和教堂入口/屋顶模块。以 32×32 Tile 为尺度，低饱和褐色、苔绿、冷灰石材和少量酸液绿/火光橙，硬像素边缘，无角色与现代物件。
