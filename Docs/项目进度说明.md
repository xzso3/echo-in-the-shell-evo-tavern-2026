## 1. 当前成果

2026-09-22 新增独立 `Assets/Scenes/BossArena.unity`：整备、两阶段 WARDEN-01、点射 / 轰炸 / 电网、医疗与装备补给、胜败与重开已经实现。Boss 专项 43 项、原城市装备 45 项、对话 27 项复验通过，242 个场内位置的裸装逃离几何采样通过；运行与验证边界见 [Boss 关卡实现与验证](Boss关卡实现与验证.md)。原 CyberCity 场景文件哈希保持不变。下文的城市玩法说明仍适用于原生存场景。

项目已完成“移动躲避 → 自动索敌射击 → 敌人持续生成并追击 → 受伤死亡 → 重开”的基础循环。当前版本采用赛博都市题材，玩家为义体特勤，敌人为持电击棍的近战士兵和被劫持的远程安保机器人。

最初的中世纪丧尸庭院原型已保留为历史场景，当前开发入口是 `CyberCity`。原始需求中的全向移动、自动索敌与攻击、固定地图、安全距离随机刷怪、两类敌人及敌人索敌均已实现。

目前已新增 24 格背包、三个装备栏位、五档品质、武器攻击力、怪物掉落及靠近吸附拾取，详见 [背包装备与掉落系统](背包装备与掉落系统.md)。开局不再赠送测试装备。尚无经验升级和关卡通关系统，仍以基础战斗与场景原型验证为主。

新增角色立绘、名称与正文、最多四项分支选择的基础对话系统，按 F 打开测试对话。配置与验证边界见 [对话系统](对话系统.md)。文档入口见 [开发文档索引](README.md)。

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 全向移动 |

| Tab | 在跟随镜头和全城视图之间切换；不暂停战斗 |
| ESC | 对话或背包打开时关闭该面板；其余情况下暂停 / 继续 |

| 1～4 / 鼠标 | 对话中选择对应选项；无分支时 Space / Enter 继续 |

HUD 显示生命、击杀数和存活时间。生命归零后显示死亡界面。目前游戏内文字为英文。

## 3. 已实现功能

| 模块 | 实现情况 |
| --- | --- |
| 玩家移动 | 全向移动，输入长度归一化，避免斜向速度增加 |
| 自动攻击 | 自动选择最近可见目标，按攻击间隔发射直线投射物 |
| 玩家生命 | 受伤扣血、短暂无敌、颜色闪烁反馈、死亡与重开 |
| 近战敌人 | 追踪玩家、绕障、近距离造成伤害，不发射子弹 |
| 远程敌人 | 追踪玩家，进入合适距离后停留射击，过近时尝试后退 |
| 刷怪 | 全地图随机采样，避开玩家安全范围、实体障碍和不可达网格 |
| 障碍移动 | 移动拆成小步，并分别处理 X/Y 方向，支持沿障碍滑动 |
| 敌人寻路 | 多个敌人共享以玩家为终点的网格距离场 |
| 敌人分离 | 简单邻近分离，减少多个敌人完全重叠 |
| 射击遮挡 | 自动索敌、远程射击检查视线；弹丸碰到主要实体障碍后消失 |
| 命中检测 | 使用投射物本帧扫过的线段检测，降低高速弹丸漏判风险 |
| 相机 | 正交跟随、边缘限制、宽高比适配、全城视图 |
| 背包装备 | 24 格背包，武器/鞋子/配件三栏，品质数值、穿脱替换、删除确认 |
| 掉落拾取 | 击杀概率掉装、五档品质光柱、靠近吸附、遮挡检查、满包保留掉落 |
| 分支对话 | 测试立绘、名称正文、最多四选项、连续台词、返回与结束；与背包互斥 |

敌人的攻击和伤害逻辑已实现，但尚未配套完整的挥棍、射击、受击与死亡逐帧动画。

### 刷怪

| 参数 | 数值或规则 |
| --- | --- |
| 初始敌人 | 4 个近战、1 个远程；位置采样成功时生成 |
| 后续远程生成概率 | 28% |
| 距玩家最小距离 | 8 单位 |
| 配置刷怪间隔 | 0.8 秒，随存活时间递减，最低 0.42 秒 |

刷怪当前由程序动态选点，并未摆放固定出生点 GameObject；其逻辑独立于地面 Sprite。

## 5. 地图与美术进度

### 地面

最新版本已从拼片地面升级为单张背景，采用 `cyber_ground_64x44_32px.png`。

| 属性 | 配置 |
| --- | --- |
| 原始尺寸 | 2048×1408 像素 |
| Texture Type / Sprite Mode | Sprite / Single |
| Pixels Per Unit | 32 |
| Pivot | Center，对应像素位置 (1024,704) |
| 世界尺寸 | 64×44 单位 |
| 场景位置 / 缩放 | (0,0,0) / (1,1,1) |
| Sorting Layer | 独立 Ground，顺序低于 Default |
| 采样与压缩 | Point、无压缩、关闭 mipmap |

旧地面的 786 块拼片保留在 `Legacy tiled ground - disabled` 对象下，整组停用。当前只有一张启用的地面 Sprite，避免与旧地面叠加。

### 建筑、装饰与碰撞

355 个独立环境物件继续使用 `cyber_city_tileset_atlas.png`。场景保留四组功能街区：电力交换区、安保节点、服务街区和冷却维护区，包含设备柜、围栏、岗亭、路障、售货机、摄像头、空调、涡轮、花箱及垃圾设施。

地图范围为 64×44 单位，约为原 28×16 庭院面积的 6.3 倍。地面背景与物件分开编辑；背景中的道路、积水和排水设施属于视觉内容，不会自动生成碰撞。

115 处实体障碍由 `CyberCityWorld.obstacles` 的矩形数组控制，覆盖主要设备岛、路障、部分围栏和地图外缘。小型装饰不全部参与碰撞。当前没有为每件物体自动生成 Collider，也没有采用 Tilemap Collider 或 NavMesh。

## 8. 已知限制与未实现内容

| 范围 | 当前限制 |
| --- | --- |
| 动画 | 没有完整四方向行走、挥棍、射击、死亡动画 |
| 美术 | 母图非严格网格成品；轮廓、背景残留、帧间一致性仍需清理 |
| 关卡编辑 | 美术位置与障碍矩形分开维护，移动物件不会自动更新碰撞 |
| AI | 静态矩形障碍和简单距离场；未系统覆盖复杂狭窄地形、动态障碍及拥堵情况 |
| 性能 | 敌人分离使用两两遍历；敌人和弹丸仍使用 Instantiate/Destroy，尚无对象池 |
| 平衡 | 生命、伤害、速度和刷怪节奏是初步参数，尚未系统调优 |
| 成长 | 已有怪物掉落、五档品质装备与背包；无经验、升级选项、强化或技能构筑 |
| 目标 | CyberCity 仍为无尽生存；独立 BossArena 已有两阶段 Boss、胜利条件和完整关卡流程，无跨场景衔接 |
| 对话 | 当前为 F 键测试入口和英文示例；未接入 NPC 触发、剧情条件、奖励或对话存档 |
| 表现 | 无已接入的完整音乐音效、正式特效与伤害数字系统 |
| 产品功能 | 无主菜单、设置、存档、手柄与移动端操作适配 |
| 发布 | 未打包可执行程序，未开展目标设备性能和分辨率兼容测试 |

## 9. 当前待验证事项与开发范围

- 对话顶部、底部遮挡的最终截图，以及真实鼠标点击和 F、数字键、ESC 操作仍待复验。
- 对话的长文本、多分辨率适配，以及装备掉落长期堆积性能尚未验证。
- 未导出独立程序；编辑器内检查不代表发布平台验收。

此前提出的动画、碰撞维护、音效、存档等缺口暂不安排实现。它们保留在“已知限制”中作为现状说明，后续开发范围以用户新需求为准。

## 10. 当前阶段交付状态

独立 BossArena 首版已交付，可在编辑器直接打开试玩；首轮功能、画面和真实输入验证已完成。普通装备的自动持续命中用时短于原计划目标，真人难度、多轮通关与长期性能仍待后续验证；未打包独立程序。

当前已具备赛博街区生存战斗、24 格背包与五档品质掉落、固定怪物生命和基础分支对话。对话功能检查与装备回归已有通过记录，最终对话视觉及真实输入复验尚未完成。开局赠装的旧测试方案已废弃，当前维护入口为本页及两份系统专题文档。
