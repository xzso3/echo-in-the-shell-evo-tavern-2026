# 基础装备系统

> 历史版本说明：本页记录两件初始装备的测试阶段，已被 [背包装备与掉落系统](背包装备与掉落系统.md) 替代。当前开局无装备，装备通过击杀怪物掉落获得。

更新日期：2026-09-21

第一版提供两件初始装备，默认在背包中、未穿戴。每个部位只能穿戴一件，当前包括 Feet（鞋）和 Module（模块）。界面沿用现有英文显示。

| 装备 | 词条 | 穿戴效果（当前场景基础值） |
| --- | --- | --- |
| Mobility Boots（移速鞋） | 移动速度 +20% | 4.5 → 5.4 单位/秒 |
| Reflex Module（攻速模块） | 攻击速度 +20% | 0.48 → 0.40 秒/发，约 2.08 → 2.50 发/秒 |

## 操作

- E：打开/关闭装备面板。面板打开时暂停战斗。
- Equip / Unequip：穿戴/卸下对应装备，属性即时更新。
- Close、E 或 ESC：关闭面板；如果打开前已通过 ESC 暂停，关闭后仍保持暂停。
- R：重开，恢复初始两件装备未穿戴状态。
- 死亡后无法打开装备面板或更换装备。

## 计算与维护

- 最终移速 = 基础移速 ×（1 + 已穿戴装备移速词条之和 / 100）。
- 最终射击间隔 = 基础间隔 ÷（1 + 已穿戴装备攻速词条之和 / 100），最低 0.01 秒。
- 装备变更按比例调整剩余攻击冷却，保留当前冷却进度，防止反复穿脱刷新射击。
- 基础属性不被穿戴操作改写；卸下后重新计算，避免加成累积。
- `Assets/PlagueSurvivor/Scripts/PlayerEquipment.cs`：装备数据、部位和属性计算。百分比填写 20 表示 +20%。初始装备可在 PlagueGame 的 Equipment 配置中调整。
- `Assets/PlagueSurvivor/Scripts/EquipmentPanel.cs`：运行时在现有 HUD 下创建 Canvas 装备面板，复用字体和 EventSystem。
- `Assets/PlagueSurvivor/Scripts/PlagueGame.cs`：移动、攻击、暂停和重开接入。不需要重新生成 CyberCity 场景。

当前只提供初始装备与穿脱验证，不包含掉落、随机词条、强化、跨局存档。
