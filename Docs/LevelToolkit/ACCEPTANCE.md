## 4. 测试执行入口

本轮不要求实现任务提供 Edit Mode／Play Mode 测试套件。仅当最小故障复现需要使用已有测试入口时，先核对本工程 Editor 和包版本支持的参数。下列为约定模板，不是已执行命令；`$UNITY_EDITOR`、`$TEST_PROJECT` 和输出目录由主控解析为验证过的路径：

```sh
"$UNITY_EDITOR" -batchmode -projectPath "$TEST_PROJECT" -runTests -testPlatform EditMode -testResults /tmp/echo-toolkit-edit.xml -logFile /tmp/echo-toolkit-edit.log
"$UNITY_EDITOR" -batchmode -projectPath "$TEST_PROJECT" -runTests -testPlatform PlayMode -testResults /tmp/echo-toolkit-play.xml -logFile /tmp/echo-toolkit-play.log
```

涉及渲染和截图的检查使用可渲染的编辑器会话，不直接套用 `-nographics`。同一 checkout 被用户 Editor 打开时，不运行第二个批处理。退出码、XML和日志一起检查；没有测试结果不能凭无错误输出判通过。

现有 `Tests/EchoFramework/Contracts/verify.sh` 仅在确实改动共享契约或对应依赖时运行，不能把它当新关卡系统验收。不得为了工具包恢复历史 P1 的全套独立引擎验收。
