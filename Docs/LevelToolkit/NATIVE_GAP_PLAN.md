# Native 本体能力差距与补齐计划

日期：2026-09-23。状态：静态核验后的开发计划，未执行。本文补充 [开发方案](DEVELOPMENT_PLAN.md)，是发布前置条件，不是可选优化。

本轮速度优先：本文验收描述作为功能目标，实际必需检查仅S1～S4；NB-04全量主线回归、B01～B08专门测试和完整人工验收后置。

## 1. 判断原则

“工具包中可试玩”不等于“本体可接收”。每项对外运行能力必须有本体接入实现和验收；否则不得宣称作品可加入正式游戏。共享运行能力只开发一份，Native 与独立宿主复用；本体专有任务、叙事、手机和正式结束流程仍留在主项目。

以下差距覆盖本轮需求及当前 NativeGame 静态核验范围。它不宣称旧原型从未实现相似能力，也不把未经运行验证的源码判为已验收。执行 G0 时继续核对实际场景／Prefab，更新差距状态。

## 3. 本体新增开发任务

KT 是共享实现或制作工具的唯一任务编号；下面 NB 仅承接主项目专属补齐，避免对同一代码重复派发。

### NB-01：正式关卡挂载与运行桥接

依赖：KT-01、KT-03、KT-05、KT-06；可在 KT-01 后先编写接口适配骨架。

修改归属：`Assets/NativeGame/ToolkitIntegration/LevelHost/`；现有 RunController／Map／Camera 的必要适配由集成负责人审查应用。

交付：明确注册的关卡实例、内容引用、出生点／相机范围配置、门与端点目录、挂载／卸载清理。主 Run 生命周期不依赖关卡测试终点；作品从编辑器选择后才能进入挂载集合，不自动导入即运行。首版支持同一场景内关卡实例接入，不新增跨场景传送、流式世界或存档系统。

验收：同一作品两实例端点／门隔离；32格与混合地图实际行走／相机跟随；实例卸载不结束整局、不触发伪胜利；死亡／重开清理所有实例。NativeDemo 保留原场景配置和默认行为。

### NB-02：输入、Boss 目标与手机支援兼容

依赖：KT-02、KT-05、KT-06、NB-01 接口冻结。

修改归属：ToolkitIntegration 的目标选择／输入桥接；NativeHud、NativeInteraction、Support/NativeSupportController 的窄范围适配。

工作：把固定交互数组扩展为可登记的关卡局部候选；以实际距离、视线、运行／实例归属和核心窗口选择 Boss，多个候选时确定性排序。保持对白优先、输入焦点屏蔽、同帧确认保护及原 E／Space／Tab／Enter 行为。

支援合同继续绑定接受时核验的具体目标；切换关卡／Boss 或目标失效使旧合同取消或拒绝，不能悄悄作用到新 Boss。既有“每局每项一次”和支援计分保持，不改成每 Boss 重置。不为普通创作者开放支援或手机编辑。

验收：两个 Boss 中 E 只作用于可达目标；另一实例不被误激活；旧弱点合同不影响新 Boss；医疗、弱点解析、手机和文本输入回归通过。

### NB-03：任务与叙事的最小外来关卡扩展

依赖：KT-06、NB-01；与 NB-02 在不同文件上可并行。

修改归属：ToolkitIntegration 的正式绑定目录；NativeQuest、NativeNarrative 的必要扩展。一个负责人独占这两个状态拥有者。

工作：任务拥有者提供按稳定目标键接收已验证关卡事实的窄接口，支持本轮外来关卡必需目标；规则读取任务条件后调用关卡动作。Narrative 对外来事实使用任务／剧情语义键并附关卡来源，避免不同关卡共用 `boss` 或 `bypass` 自动计分。

保留原主线三记忆、Relay、单 Boss 流程、四结局和阈值。只有显式正式绑定才可将某个外来 Boss 完成映射成原主线 Boss 目标；任意关卡完成不能自动调用 CommitEnding。新外来事实默认不加同步／差异；正式绑定只能调用已有允许的叙事动作，不新增任意分数执行器。

交付：少量 Unity 配置绑定、局部事实去重、现有对白／记忆动作映射及完成条件查询；不开发通用任务图、剧本编辑器、无限记忆类别或跨进程持久化。

验收：两个不同关卡事实各记录正确且同一事实不重复结算；无法伪装成原主线 Boss 胜利；显式映射能实际推进目标；正式最终条件仍由原主线控制。若现有任务结构无法在此边界内接入，提交具体差距，不擅自重写整个叙事系统。

### NB-04：本体接入样例与完整回归

依赖：KT-07、NB-01～03、KT-08。

修改归属：新增 NativeToolkitIntegration 场景、集成夹具与报告；由集成负责人独占 Unity 保存。

工作：从真实导出的作品包接入新增场景；验证可复用作品在 Sandbox／Integrated 两模式；通过玩家真实互动推进 Quest／Narrative，正式条件开门或激活遭遇；运行原 NativeDemo 核心路线回归。

本轮检查：S4真实正式接入；必要时S1原场景启动。B01～B08完整验证后置；新增作品不直接结束整局，保留原组件GUID和引用，不重建旧场景。用户未授权重新设计的故事、结局、支援、NPC 支线保持既有语义。

| 本体里程碑 | 唯一实现任务 | 工具包解锁 |

| 公共上下文与标准战斗可复用 | KT-01、KT-02 | 独立试玩模板 |
| Tilemap 地形与接口可运行 | KT-03、KT-04、NB-01 | 地图包可进入本体 |
| 多遭遇与门集合可运行 | KT-05、NB-01 | 清敌／Boss 关卡可进入本体 |

| 正式任务与叙事消费接口 | NB-03、KT-07 | 作品真正推进完整游戏叙事 |
| 接收样例及存量回归 | NB-04 | 工具包正式发布 |

KT-07 负责绑定演示与交接，NB-03 负责真正的任务／叙事状态 API；二者不能同时修改 NativeQuest／NativeNarrative。主控按任务归属集成。

## 5. 不因补齐本体而扩大的范围

工具包需要的最小能力不等于新一代完整游戏框架。首版仍不包含流式大世界、跨场景传送、保存／读档、网络多人、波次生存、Boss 新机制、剧情节点编辑器或全面替换原生主线。编辑器技能安装、图像生成、资源导出属于工具侧，不进入本体 Runtime。

地图接收和叙事接线在本轮应具备可工作的最小实现；真实新剧本与完整后续章节内容仍由单独内容需求决定。
