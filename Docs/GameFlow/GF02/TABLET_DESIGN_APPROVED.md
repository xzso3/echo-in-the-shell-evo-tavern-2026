## 统一视觉与适配

- 保留现有平板外壳、物理返回键、通讯/支援/记录底部导航及像素美术风格。
- 紧凑单行页头；中部主题/分类与正文；必要的操作区；独立固定主导航。
- 枪灰机壳、墨绿屏幕、灰白正文、磷光绿选中项；琥珀用于授权和提醒。状态同时使用文字，不能只靠颜色。
- 正文不叠扫描线，不通过缩字挤入全部内容。普通重要文字对比度目标至少 4.5:1，禁用说明仍须可读。
- 16:9/16:10 均保持外壳等比完整显示与屏内安全边距；不拉伸机壳。正文纵向滚动，操作区/导航不随正文滚动，不允许横纵双向阅读。
- 图片是比例与层级参考，未冻结全部像素坐标。具体字号、行高、按钮最小高度和字体实际字面高度须在后续实施验收中确定。

## 通讯：邮件式本地阅读

顶部主题为任务、记忆、身份、授权。任务默认进入列表，每项展示标题、真实状态和一至两行预览；点击整行进入详情。列表预览中的找回信号、本地档案员委托、行动简报来自现有任务/支线/预设内容，不新增任务规则。

详情展示当前目标与完整说明，长文可滚动；返回先回列表并保留滚动位置，随后才关闭平板。切换主导航保留页面阅读状态。主题不虚构发件人、时间、未读计数或已收到邮件事件。

本地预设与本局状态明确区分。离线/未配置状态不出现自由输入框、发送或取消请求按钮，不模拟等待、思考和任意问答。GF02 已有本地主题接线，应复用内容来源，整理为列表/详情展示，而非重复追加同一主题至聊天历史。

## 在线通讯状态规格

已配置时，通讯提供本地简报/在线通讯入口；只有主动进入在线通讯且安全节点允许输入时才出现输入区。此处为文字交互规格，尚无单独获批的在线视觉稿。

| 状态 | 显示与交互 |
| --- | --- |
| 离线/未配置 | 本地主题与真实状态可用，无输入区 |
| 已配置未验证 | 明确显示已配置、尚未验证，不等同连接成功 |
| 请求中 | 显示正在请求，避免重复发送，允许取消 |
| 成功 | 显示上次请求成功/已收到回复，不暗示持续连接 |
| 失败 | 原因就近显示、草稿保留、手动重试，无自动重试 |
| 已取消/状态变化 | 明确表示取消或结果失效 |
| 不在安全节点 | 保留阅读，输入区域改为位置限制原因 |
| 共享通道忙 | 说明当前通道被占用，不能误报为成功或离线 |

GF02 已有 `LastOnlineStatus` 和本地来源标记；复用现有状态，不改 SDK。切换主页面不取消请求，关闭平板、配置变更和原有生命周期失效规则继续生效。最终决策态沿用取消旧请求与导航限制。

## 支援

依次展示支援类型（医疗/弱点）、授权档位（有限/深度及同步变化）、记忆选择。已选、可用、不可用、已使用须可区分，不可用原因贴近当前选项。

选择与说明可滚动；固定操作区显示当前条件和「查看授权合同」。合同依旧由本地真实服务生成：查看 → 核对效果/记忆/授权范围/同步变化 → 接受并执行或拒绝。接受前复核，失效不执行；关闭/拒绝走既有取消逻辑，不擅自重试或收费。只允许一个待确认合同，不覆盖其他待确认操作。

预览是尚未找回记忆的不可用状态；正常可用、待确认、已执行、失效、拒绝等状态需要后续实现。合同本身未单独生成获批视觉稿，保持原确认语义。

## 记录

目录包括本局记录、记忆档案、本局行为、同步与差异、初始回声；进入详情阅读，返回目录时保留位置。长目录/正文在自身内容区域滚动。

任务、记忆说明、身份和授权说明的重复入口整合到通讯本地主题，但不删除内容。保留异议放在私人记忆详情旁；改写初始回声放在相应详情旁；已完成显示真实结果，未满足条件显示原因。所有动作继续调用原规则与一次性条件。

最终写入/销毁仍由原剧情触发，使用独立决策视图并沿用 GF02 导航锁定和退出规则；新生接续保留原文本，不宣称全服网络已接入。普通记录目录的返回规则不能覆盖最终决策规则。

## 诊断更正与未验证范围

已更正旧工作树误判：GF02 本地主题已接通；安全节点内离线自由输入会给本地反馈；请求成功/失败状态已经存在。重新设计针对这些行为的呈现与入口，不把它们写成缺失能力。

GF02 `RenderReading` 的动作按钮只设置 RectTransform 高度，父 VerticalLayoutGroup 控制高度，按钮缺少明确的 LayoutElement 高度；文字允许溢出。这与两张截图的按钮堆叠吻合，是静态诊断，尚未运行确认。

本任务未启动 Unity Editor、未修改游戏代码/场景/资源、未写跑测试/mock/截图巡检。未验证：Unity 导入编译、真实输入与焦点、16:9/16:10 与低分辨率、实际中文渲染/对比度、长文本与滚动恢复、真实 API、共享传输、合同全过程、一次性剧情动作、最终决策与新生接续。图片获批不等于功能或兼容性验收。
