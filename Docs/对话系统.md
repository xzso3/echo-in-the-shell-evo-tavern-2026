# 基础分支对话系统

更新日期：2026-09-21。已接入 CyberCity 场景；当前为测试对话入口及可编辑的分支脚本。

## 操作与行为

| 操作 | 效果 |
| --- | --- |
| F | 打开测试对话；对话中再次按 F 关闭 |
| 鼠标点击选项 / 主键盘 1～4 | 选择对应的可见选项 |
| Space / Enter | 无分支的节点继续下一句，或结束对话 |
| ESC / Close | 关闭对话 |
| R | 重开本局，同时关闭对话、清空本局装备和掉落 |

- 立绘位于左上，分支选项位于右上，主对话框位于下方，包含角色名称和正文。
- 主对话框保持 4:1，选项框保持 8:1；立绘保持原比例。最多显示四个选项。
- 对话期间暂停战斗模拟，包括移动、自动攻击、刷怪、计时和装备吸附。关闭后恢复此前的暂停状态；若原本手动暂停，不会直接恢复战斗。
- 背包和对话互斥；死亡时不能开启对话。重开和死亡都会关闭对话。
- 重新打开从入口节点开始，不保存上次对话进度。
- “对话脚本选择框”当前实现为剧情分支选项，不是运行时选择不同脚本文件的菜单。

## 配置对话脚本

当前测试资产：`Assets/CyberCity/Resources/TestDialogue.asset`。场景的 `PlagueGame.testDialogue` 已引用该资产；未指定时尝试加载 Resources 中的 `TestDialogue`。

在 Project 窗口通过 Create → Neural Lockdown → Dialogue Script 创建新资产，在 Inspector 编辑以下字段：

| 字段 | 用途 |
| --- | --- |
| Panel Image / Option Image | 主对话框与选项背景 Sprite |
| Default Portrait | 默认角色立绘 |
| Font | 可选 TMP 字体；空值沿用 HUD 字体 |
| Title | 顶部对话标题 |
| Entry Node | 起始节点下标，从 0 开始 |
| Nodes | 对话节点数组 |
| 节点 Speaker / Text | 角色名称及正文 |
| 节点 Portrait | 当前节点立绘；空值使用默认立绘 |
| 节点 Next Node | 没有选项时的下一节点；-1 表示结束 |
| 节点 Choices | 最多四个选项，每项包含 Text 和 Next Node |

有 Choices 时，以选中的选项目标跳转，忽略节点自身的 Next Node。目标可以指向前面的节点以实现返回提问。调整数组顺序后，需要同步更新引用下标。

启动前会检查入口、正文、选项数量、选项文本和目标下标；无效脚本会拒绝开启并输出警告。正文及选项当前整段显示，无打字机效果或滚动阅读。当前测试内容为英文；使用中文前需配置覆盖相应字符的 TMP 字体。

测试脚本的四个节点：

| 下标 | 内容 | 跳转 |
| --- | --- | --- |
| 0 | 联系人询问需要什么信息 | 战况 → 1；装备 → 2 |
| 1 | 战况与躲避提示 | 返回 → 0；结束 → -1 |
| 2 | 掉落、吸附与背包说明 | Continue → 3 |
| 3 | 三类装备属性说明 | 返回 → 0；结束 → -1 |

后续交互可调用 `PlagueGame.StartDialogue(script)`，返回是否成功开启；`CloseDialogue()` 关闭。当前未接入 NPC 距离触发、任务条件、奖励、配音、剧情存档或图形化节点编辑器。

## 代码与美术

| 路径 | 职责 |
| --- | --- |
| `Assets/PlagueSurvivor/Scripts/DialogueScript.cs` | ScriptableObject 数据、校验及 DialogueSession 分支状态 |
| `Assets/PlagueSurvivor/Scripts/DialoguePanel.cs` | 运行时 uGUI、立绘、布局、选项和输入 |
| `Assets/PlagueSurvivor/Scripts/PlagueGame.cs` | F 入口、暂停互斥、重开与死亡清理 |
| `Assets/CyberCity/Resources/TestDialogue.asset` | 四节点测试内容及美术引用 |
| `Assets/Art/Generated/Cyberpunk/DialogUI/` | 主框与选项框成品和美术说明 |
| `Assets/Art/Generated/Cyberpunk/charator/test-charator-avator.png` | 已接入的测试立绘 |

界面在运行时创建于现有 HUD Canvas 下的 `DialogueRoot`，不是需要手工放入场景的独立预制体。复用现有 EventSystem，顶部和底部增加不透明底板以遮挡原 HUD 文字。

主框使用 `dialogue_panel_1280x320.png`，选项使用 `dialogue_option_1024x128.png`，不使用 source 母图。UI 图片使用 Single Sprite、Full Rect、Point、无压缩、无 mipmap。测试立绘由原始 WebP 转换为 PNG 导入，原图保留；立绘采用 Bilinear。更多原始美术约定见 [资源说明](../Assets/Art/Generated/Cyberpunk/DialogUI/README.md)。
