## 启动与配置

打开 `Assets/Scenes/CommanderHome.unity` 并 Play，或从以该场景为首项的 Build Settings 启动。首页填写兼容 `/v1/chat/completions` 的 API Base URL、模型 ID、API Key；模型 ID 由使用者填写，暂定 DeepSeek V4 Flash 不表示具体 ID 已核验。超时默认 15 秒，可在首页调整。可先点“测试连接”，再点“开始游戏”；“离线试玩”不发送在线请求。两种进入方式在本机都加载 `Assets/Scenes/NativeDemoTilemap.unity`。该场景及地图依赖仍是用户未提交内容；没有它的干净检出会回退到已提交的 `Assets/Scenes/NativeDemo.unity`。

URL、模型和超时在本机保存；Key 只驻程序内存，重开本局保留，退出程序清除。不要在聊天、文档或仓库中填写真实 Key。测试连接只核对普通文本回复，不产生本局消息或支援提案。

- 游戏内手机全入口使用同一暂停状态；世界移动、攻击、弹丸、伤害、Boss 窗口、Buff 和关卡计时冻结，UI 与网络按未缩放时间继续。暂停中手动或 AI 合同仍可执行；最终演出、终局手机和重开释放本手机暂停。
- 安全节点不再因敌近禁输入；每次在线发送附当前已知状态与最近六轮成功问答。回复只接收对白和无／医疗／弱点解析提案，合法选项由 Unity 提供；取消、关闭和重开隔离迟到回复，切页不取消请求。

## 唯一人工检查单

以下由用户或指定操作者在最终版本操作一次；未操作的项目保持“待人工校验”，不要填写通过。

1. 首页填写地址、模型和 Key，测试连接并开始游戏；验证错误提示与离线试玩。重开本局仍有内存 Key，退出程序重启后不保留 Key。
2. 在安全节点打开平板，观察战斗和计时停止；发送真实消息并看到对白／合法提案。节点内敌人靠近不禁输入；离开节点只能阅读和手动支援。
3. 查看一张合同，核对效果、记忆、授权与同步变化；接受后核对实际回血或核心窗口变化，关闭手机后战斗续行。拒绝或关闭的提案不能再次执行，手动合同不被 AI 合同覆盖。
4. 等待回复时切换页签继续阅读；取消、关闭手机或重开后，旧回复和旧合同不进入当前局，不自动再请求或重复收费。
5. 检查聊天滚动、固定输入、三入口、实体返回键、中文长文本，以及记录与原最终选择／结局手机；外壳符合认可草图，无“战斗已暂停”文字。

当前没有真实 API 凭据，因此真实联网、Play Mode 手感与上述人工项目均**待人工校验**。完整 Windows 构建、跨分辨率和全主线回归不属于本阶段交付。
