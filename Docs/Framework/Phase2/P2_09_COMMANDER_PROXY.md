# P2-09 在线指挥官代理契约

当前交付仅是 Unity 客户端与受限 HTTP 契约。尚未配置真实代理地址或模型凭据；不能据此将 B9 标为通过。

## 配置与运行边界

- Windows 构建后编辑 `NativeDemo_Data/StreamingAssets/commander-proxy.json` 中的 `proxyUrl`。值应为由项目方控制的 HTTPS 代理端点；本机开发可用 `http://127.0.0.1`。局域网的非本机代理也须用 HTTPS；URL 不接受用户信息、查询参数或片段，避免把令牌带进客户端配置。`timeoutSeconds` 限制在 3–20 秒。文件只放 URL 和超时，绝不放 API 密钥、Bearer token 或任何凭据。
- Unity 客户端只向该 URL 发送 POST；不直接连接模型服务。代理在服务端读取环境变量中的服务密钥，并自行限制来源、流量、输入输出大小与费用。真实服务商和部署环境确定后，再实现其上游适配并配置端点。
- URL 留空、断网、非 200、超时、无效/迟到回复均保留草稿，通讯页的本地主题仍可使用。取消、离开安全节点、敌人接近、切换页签、关卡结束或重开都会废弃在途回复。

## HTTP v1

`POST /`（具体路径由完整 `proxyUrl` 决定），`Content-Type: application/json; charset=utf-8`：

```json
{
  "version": 1,
  "requestId": "32位十六进制请求标识",
  "message": "玩家自由文本，最多300个字符",
  "context": {
    "objective": "当前任务显示文本",
    "memories": "当前已发现记忆的显示摘要"
  }
}
```

成功时返回 HTTP 200、JSON、UTF-8、正文总量不超过 16 KiB：

```json
{
  "version": 1,
  "requestId": "原样回传请求标识",
  "reply": "最多1200个字符的纯文本"
}
```

代理只提供回复文本；不得返回可执行玩法命令。客户端不解析动作、意图、支援授权、开门、任务或结局字段，也不把回复送往这些模块。回复会以纯文本渲染。玩家若要使用支援，仍须在本地支援页查看合同并明确确认。代理应把模型输出视为不可信文本，避免将未发现的剧情、密钥或服务端内部数据放进上下文与回复。

代理应对请求做身份与速率控制，使用服务端环境变量取上游凭据，对上游超时并返回明确失败状态；不要把服务端错误原文、密钥或上游内部信息回传客户端。客户端不随包分发代理服务或密钥。

## 实网验收前置

需项目方确定模型服务、服务端部署位置与外部可达 HTTPS URL、凭据注入方式和测试网络。服务可用后，在安全节点真实发送一次文本并收到该服务的回复，再验证断网/超时后本地主题仍可用；这些检查尚未执行。Windows 构建与试玩由用户手动完成。
