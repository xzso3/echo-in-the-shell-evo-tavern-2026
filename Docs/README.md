## 现有原型规则（已实现）

以下规则说明现有原型，不覆盖核心设计中的目标规则。例如，目标输入为 Space 切换开火、E 情境互动、Tab 虚拟手机；现有 E 背包、Tab 地图和 F 测试对话尚未迁移。实时指挥官和手机不暂停战斗，不能直接套用现有暂停式对话行为。

- CyberCity 开局不赠送装备；怪物掉落装备，靠近自动吸附，背包一格一件，共 24 格。独立 BossArena 在地面提供三件战前普通装备，出生时背包仍为空。
- 武器提升攻击力、鞋子提升移动速度、配件提升攻击速度；品质为劣质、普通、稀有、史诗、传说。
- 近战出生生命固定 58，远程固定 82。已删除生命随时间增长及随机差异；刷怪间隔随时间缩短是另一项现有规则。
- 对话含角色立绘、名称与正文、分支选项。目前使用 F 键进入测试脚本。
- 原型阶段未安排的动画、音效、存档等内容，其后续范围以核心设计及后续确认的工作安排为准；历史验证记录不代表新版目标功能已经实现。
